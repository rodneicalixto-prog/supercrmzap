WhatsApp MKT
MassWhatsAppSender v11 · .NET 4.6 + Selenium + ChromeDriver · Windows

Disparador em massa de WhatsApp via automação do WhatsApp Web com Selenium + ChromeDriver. Gerencia múltiplas contas, filtra números com WA ativo, extrai contatos de grupos e envia mensagens, imagens, vídeos e documentos com personalização por variáveis.

Requisito de sistema

Windows 10 ou 11 · 64 bits. Requer .NET Framework 4.6 (já incluso no Windows 10+) e Google Chrome instalado. O ChromeDriver incluído na pasta é compatível com Chrome 114. Se seu Chrome for mais novo, baixe o ChromeDriver correspondente e substitua o arquivo.

Como instalar e usar
1
Criar pasta de instalação
Crie uma pasta no seu computador, por exemplo C:\MassWhatsApp\ e salve todos os arquivos obrigatórios nela, na mesma pasta. A estrutura deve ser:

MassWhatsApp\
  MassWhatsAppSender.exe
  chromedriver.exe
  Newtonsoft.Json.dll
  WebDriver.dll
  Lang\ (pasta com os .xml)
2
Verificar versão do Chrome
Abra o Chrome → ⋮ Menu → Ajuda → Sobre o Google Chrome. O ChromeDriver incluído é compatível com Chrome 114. Se a versão for diferente, baixe o ChromeDriver correto em googlechromelabs.github.io e substitua o chromedriver.exe.
3
Executar a ferramenta
Dê duplo clique em MassWhatsAppSender.exe. Na primeira abertura, selecione o idioma Português no menu de idiomas.
4
Conectar conta WhatsApp
Clique em "Adicionar conta" → a ferramenta abre o WhatsApp Web automaticamente no Chrome. Escaneie o QR Code com seu celular. A sessão fica salva para uso futuro.
5
Importar lista e disparar
Importe uma lista de números (.txt — um número por linha, com DDI). Use o Filtro WA para verificar quais números têm WhatsApp ativo antes de disparar. Configure mensagem, anexo opcional e delay entre envios.
